Guide The Sims 4

✦ ♡ ✦

Tutto quello che ti serve per installare mod e traduzioni e risolvere i problemi più comuni in The Sims 4.

Installare le mod

Come installare correttamente mod e script mod in The Sims 4.

1

Scarica la mod

Scarica sempre la mod dalla pagina ufficiale del suo creatore e controlla eventuali istruzioni specifiche fornite dall'autore.

2

Estrai il file

Se il download è contenuto in un file ZIP o RAR, estrailo prima di inserirlo nel gioco. Normalmente troverai file .package e, per alcune mod, file .ts4script.

3

Apri la cartella Mods

Su Windows, normalmente la cartella si trova qui:

Documenti → Electronic Arts → The Sims 4 → Mods
4

Inserisci i file

Copia i file della mod nella cartella Mods. Puoi organizzare i file .package in sottocartelle, ma presta particolare attenzione alle istruzioni del creatore per i file .ts4script.

5

Attiva le mod nel gioco

Avvia The Sims 4 e apri:

Opzioni di gioco → Altro

Attiva Contenuto personalizzato e mod. Se utilizzi mod con file .ts4script, attiva anche Mod dello script consentite. Dopo aver modificato queste opzioni, riavvia il gioco.

Installare le traduzioni

Come utilizzare correttamente una traduzione italiana AIZNUN insieme alla mod originale.

1

Installa prima la mod originale

La traduzione normalmente non sostituisce la mod. Scarica e installa prima la mod originale dalla pagina del suo creatore.

2

Scarica la traduzione

Vai nella sezione Traduzioni di AIZNUN e scarica la traduzione corrispondente alla mod che hai installato.

3

Inserisci la traduzione

Inserisci il file della traduzione nella stessa cartella della mod originale, salvo indicazioni differenti presenti nella pagina della traduzione.

Documenti → Electronic Arts → The Sims 4 → Mods
4

Non eliminare la mod originale

La traduzione contiene i testi italiani, ma la mod originale è necessaria per il funzionamento delle sue caratteristiche. Mantieni quindi entrambi i file.

✦

Dopo un aggiornamento della mod

Se il creatore aggiorna la mod originale, controlla anche la pagina AIZNUN della traduzione. Una nuova versione della mod può introdurre nuove stringhe o modificare quelle esistenti, rendendo necessario un aggiornamento della traduzione.

Problemi con le mod

Alcuni controlli utili quando una mod non appare, non funziona correttamente o presenta problemi.

1

Controlla che le mod siano attive

Dopo alcuni aggiornamenti di The Sims 4, le opzioni relative alle mod possono essere disattivate automaticamente.

Opzioni di gioco → Altro
2

Controlla la versione della mod

Verifica sul sito del creatore che la versione installata sia adatta alla versione attuale di The Sims 4.

3

Controlla le dipendenze

Alcune mod richiedono altre mod, librerie o file aggiuntivi per funzionare. Controlla sempre i requisiti indicati dal creatore.

4

Elimina la cache

Dopo aver aggiornato o rimosso una mod, può essere utile chiudere il gioco ed eliminare il file localthumbcache.package dalla cartella principale di The Sims 4. Il gioco lo ricreerà automaticamente al successivo avvio.

Documenti → Electronic Arts → The Sims 4 → localthumbcache.package
5

Prova senza la mod problematica

Se il problema continua, chiudi il gioco e sposta temporaneamente la mod sospetta fuori dalla cartella Mods. Avvia nuovamente il gioco per verificare se il problema scompare.

♕

Dopo una patch di The Sims 4

Non dare per scontato che tutte le mod siano immediatamente compatibili con una nuova patch. Controlla la sezione Compatibilità di AIZNUN e soprattutto le comunicazioni ufficiali del creatore della mod prima di utilizzare una versione non ancora verificata.
