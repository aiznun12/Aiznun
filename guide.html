Come installare le mod

✦ ♡ ✦

Una guida semplice per installare correttamente mod e traduzioni in The Sims 4.

1

Scarica la mod

Scarica la mod dal sito ufficiale del suo creatore. Se utilizzi una traduzione AIZNUN, scarica anche il relativo file di traduzione.

2

Estrai il file se necessario

Se il download è in formato ZIP o RAR, estrai prima il contenuto. I file delle mod possono essere, ad esempio, in formato .package o .ts4script.

3

Apri la cartella Mods

Su Windows, normalmente trovi la cartella delle mod qui:

Documenti → Electronic Arts → The Sims 4 → Mods
4

Inserisci i file

Copia i file della mod nella cartella Mods. Inserisci anche il file della traduzione seguendo eventuali istruzioni specifiche indicate nella pagina della traduzione.

5

Attiva le mod nel gioco

Avvia The Sims 4 e apri:

Opzioni di gioco → Altro

Assicurati che siano abilitate le opzioni per i contenuti personalizzati e le mod. Se la mod utilizza script, abilita anche le mod dello script.

✦

Dopo un aggiornamento di The Sims 4

Gli aggiornamenti del gioco possono disattivare automaticamente le mod oppure rendere alcune mod temporaneamente incompatibili. Controlla sempre gli aggiornamenti del creatore prima di riattivarle.
